# WebForge AI

Android-приложение для создания веб-страниц и веб-игр с помощью ИИ.

## Текущий этап
- Нативное Android-приложение на Kotlin + Jetpack Compose.
- Диалоговый интерфейс постановки задач ИИ.
- Предпросмотр HTML в WebView.
- Настраиваемый OpenAI-compatible endpoint, модель и ключ пользователя.
- Сборка APK через GitHub Actions.

## Сборка APK
Откройте Actions → Build Android APK. После успешной сборки скачайте артефакт WebForge-AI-debug-apk.

## Подключение модели
В настройках приложения укажите HTTPS endpoint совместимого Chat Completions API, модель и API-ключ. Ключ хранится локально на устройстве. Не публикуйте его в репозитории.

Ранняя версия: генерация требует доступного API совместимой модели. Replit и платные конструкторы не используются.
